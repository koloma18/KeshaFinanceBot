# SPEC.md — Phase 1: Core Telegram Bot + Google Sheets

**Phase:** 1
**Project:** Financial Tracker
**Core Value:** Быстрая запись расходов/доходов через Telegram с бурчливым персонажем
**Requirements:** INFRA-01, INFRA-02, INFRA-03, TG-01, TG-02, TG-03, TG-04, CAT-02

---

## 1. Goal

Создать работающего Telegram-бота v1, который записывает доходы и расходы в Google Sheets, показывает базовую статистику и общается в стиле бурчливого персонажа.

---

## 2. Requirements

### 2.1 Google Sheets — структура данных

**Current state:** Таблицы нет.
**Target state:** Лист `Transactions` с колонками: Month, Date, Type, Amount UAH, Amount USD, Amount EUR, Category, AI Comment, Source.
**Acceptance:** После запуска `formatSheet()` в Apps Script создаются заголовки, форматирование, валидация типов.

**Current state:** Цветов нет.
**Target state:** Категории раскрашиваются разными цветами при выборе (onEdit).
**Acceptance:** При вводе категории строка окрашивается в соответствующий цвет.

**Current state:** Отчётов нет.
**Target state:** Функция `generateMonthlyReport()` создаёт лист с группировкой по месяцам и категориям, включая доходы/расходы/баланс.
**Acceptance:** После вызова из меню создаётся лист Report с корректными суммами.

### 2.2 Telegram Bot v1 — команды

**Current state:** Бота нет.
**Target state:** Бот отвечает на 12 команд. Все команды работают через python-telegram-bot.

**COMM-01 — /start**
- Показывает приветствие + главное меню с кнопками
- Acceptance: Кнопки: Доход, Расход, Статистика, Последние операции, Настройки

**COMM-02 — /help**
- Показывает список команд с примерами
- Acceptance: Содержит примеры /income и /expense

**COMM-03 — /income СУММА КАТЕГОРИЯ КОММЕНТАРИЙ**
- Записывает доход в Google Sheets. Валидирует: сумма > 0
- Acceptance: После ввода бот подтверждает запись с эмодзи

**COMM-04 — /expense СУММА КАТЕГОРИЯ КОММЕНТАРИЙ**
- Записывает расход в Google Sheets. Валидирует: сумма > 0
- Acceptance: После ввода бот подтверждает с бурчливым комментарием

**COMM-05 — /today**
- Показывает доходы, расходы, итог за сегодня
- Acceptance: Числа совпадают с данными в Google Sheets

**COMM-06 — /week**
- Показывает статистику за текущую неделю
- Acceptance: Данные за 7 дней

**COMM-07 — /month**
- Показывает статистику за текущий месяц
- Acceptance: Данные за месяц с итогом

**COMM-08 — /balance**
- Показывает текущий баланс (все доходы минус все расходы)
- Acceptance: Число совпадает с Google Sheets

**COMM-09 — /categories**
- Показывает список категорий доходов и расходов
- Acceptance: Категории с эмодзи

**COMM-10 — /last**
- Показывает последние 5 операций
- Acceptance: Вывод с датой, суммой, категорией, комментарием

**COMM-11 — /delete_last**
- Удаляет последнюю операцию
- Acceptance: Операция удалена из Google Sheets, бот подтверждает

**COMM-12 — /settings**
- Показывает текущие настройки
- Acceptance: Валюта, стиль, мат, эмодзи, стикеры

### 2.3 Кнопочный интерфейс (inline-кнопки)

**Current state:** Нет.
**Target state:** После /start и после операций появляются inline-кнопки для быстрого действия.

**Acceptance (кнопка "➖ Расход"):**
1. Бот спрашивает сумму → пользователь вводит число
2. Бот показывает категории кнопками → пользователь выбирает
3. Бот спрашивает комментарий → пользователь вводит
4. Бот сохраняет и отвечает с комментарием персонажа
5. После: кнопки "Добавить ещё", "Отменить последнюю", "Показать день"

**Acceptance (кнопка "➕ Доход"):**
1. Бот спрашивает сумму → пользователь вводит
2. Бот показывает категории доходов кнопками
3. Бот спрашивает комментарий
4. Бот сохраняет и отвечает

### 2.4 Персонаж — бурчливый надзиратель

**Current state:** Нет.
**Target state:** Бот выбирает случайный ответ из набора фраз для каждого действия.

**Acceptance — разные ответы:** При 5 одинаковых /expense на кофе — каждый раз разные ответы (минимум 3 уникальных шаблона на категорию).

**Acceptance — контекст:**
- Маленький расход (< 500): лёгкий сарказм
- Средний (500-2000): бурчание
- Большой (> 2000): жёсткий комментарий
- Ночной (23:00-06:00): "покупать ночью — плохая идея"
- Повтор категории за день: "опять?"

**Acceptance — настройки:**
- Стиль: мягкий / бурчливый / жёсткий / случайный
- Мат: вкл/выкл
- Эмодзи: вкл/выкл

### 2.5 Интеграция Telegram → Google Sheets

**Current state:** Нет.
**Target state:** Все операции из бота записываются в Google Sheets через Google Sheets API.

**Acceptance:** После /income или /expense данные появляются в таблице в течение 5 секунд.

**Acceptance:** Бот читает данные из таблицы для /balance, /today, /week, /month.

## 3. Boundaries

### In Scope

- Telegram bot v1 (12 команд + кнопки)
- Google Sheets как единственное хранилище
- Apps Script скрипт для таблицы
- Персонаж с разными ответами
- Три валюты: UAH, USD, EUR
- Настройки пользователя (стиль, мат, эмодзи)

### Out of Scope

- Бюджет и лимиты по категориям — Phase 2
- Цитаты дня — Phase 2
- Стикеры — Phase 2
- Экспорт данных — Phase 2
- Веб-приложение (PWA) — Phase 3
- Monobank API — Phase 4
- Несколько пользователей — личный проект
- Нативное мобильное приложение — не планируется

---

## 4. Constraints

- **Telegram API:** сообщение ≤ 4096 символов
- **Google Sheets API:** 60 запросов/мин на пользователя, 500 запросов/100 секунд
- **Apps Script:** 6 минут выполнения на один запуск
- **Python бот:** нужен всегда включённый сервер или хостинг (Railway/Render)
- **WebHook бота:** нужен публичный HTTPS URL
