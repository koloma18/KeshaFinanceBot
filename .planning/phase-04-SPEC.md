# SPEC.md — Phase 4: Monobank Integration

**Phase:** 4
**Project:** Financial Tracker
**Core Value:** Автоматический импорт транзакций из Monobank — безналичные расходы/доходы без ручного ввода
**Requirements:** MONO-01, MONO-02, CAT-01

---

## 1. Goal

Автоматизировать учёт безналичных операций через Monobank API: импорт выписки за период, WebHook для real-time транзакций, автоматическая категоризация по MCC, конвертация валют и команды для управления.

## 2. Requirements

### REQ-01: Monobank API Client

**Current state:** Нет. Код не взаимодействует с Monobank.
**Target state:** Модуль `mono/client.py` — асинхронный клиент Monobank API с rate limiter'ом и обработкой ошибок.

**Детали реализации:**

- Базовый URL: `https://api.monobank.ua`
- Асинхронные запросы через `httpx.AsyncClient` (уже есть в зависимостях проекта)
- X-Token из `.env` → `MONOBANK_X_TOKEN`
- Rate limiter: 1 запрос в 60 секунд (блокировка, если лимит не исчерпан)
- Обработка HTTP 429 (Too Many Requests) — exponential backoff
- Таймаут запроса: 10 секунд
- Все суммы из Monobank в копейках/центах → конвертация в гривны/доллары (÷100)

**Методы клиента:**

| Метод | Endpoint | Описание |
|-------|----------|----------|
| `get_client_info()` | `GET /personal/client-info` | Информация о клиенте и счетах |
| `get_statement(account, from_ts, to_ts)` | `GET /personal/statement/{acc}/{from}/{to}` | Выписка по счёту |
| `set_webhook(url)` | `POST /personal/webhook` | Установка WebHook URL |
| `get_currency_rates()` | `GET /bank/currency` | Курсы валют (публичный, без токена) |

**Формат ошибок:**

```python
class MonobankError(Exception):
    def __init__(self, status_code: int, message: str):
        self.status_code = status_code
        self.message = message
```

**Acceptance:**
- Клиент создаётся с X-Token из конфига
- Rate limiter не даёт сделать запрос раньше чем через 60 секунд
- HTTP 429 → автоматическая пауза + повтор
- Все методы возвращают корректные данные или выбрасывают `MonobankError`
- `get_statement()` конвертирует amount из копеек в гривны (÷100)

### REQ-02: Import Statement — `/mono_import`

**Current state:** Нет. Все операции только ручные (через Telegram).
**Target state:** Команда `/mono_import [days=7]` — импорт выписки из Monobank в Google Sheets с дедупликацией и прогрессом.

**Параметры:**
- `days` — количество дней для импорта (по умолчанию 7, максимум 31)
- Если параметр не указан — последние 7 дней

**Алгоритм импорта:**

1. Получить список счетов через `get_client_info()`
2. Для каждого счета:
   a. Запросить выписку: `from_ts = now - days*86400`, `to_ts = now`
   b. Получить все существующие ID транзакций из Google Sheets (колонка Source содержит `mono:{id}`)
   c. Отфильтровать транзакции — пропустить те, чей `id` уже есть в Sheets
   d. Для каждой новой транзакции:
      - Определить MCC-категорию (REQ-03)
      - Конвертировать amount (копейки → гривны, ÷100)
      - Определить тип (income/expense по знаку amount)
      - Добавить строку в Google Sheets с source = `mono:{transaction.id}`
3. Показать итог: сколько найдено, сколько новых добавлено, сколько пропущено (дубликаты)

**Пагинация:**
- Если в ответе пришло 500 транзакций — возможно, есть ещё
- Разделить временной диапазон пополам и запросить вторую половину
- Повторять пока не получим < 500 транзакций

**Прогресс-бар:**
- Показывать прогресс: "Запрос 1/4... Добавлено 120 транзакций"
- Учитывать rate limit — между запросами пауза 60 секунд
- Если запросов много — показывать "⏳ Подожди 60 сек, лимит Monobank..."

**Пример вывода:**
```
📥 Импорт за 14 дней

Счёт: UA***1234 (UAH)
✅ Добавлено: 34 транзакции
⏭ Пропущено (уже есть): 12
📊 Итого за период: доход +15 200 UAH, расход -8 450 UAH
```

**Acceptance:**
- `/mono_import` без аргументов импортирует за 7 дней
- `/mono_import 31` импортирует за 31 день
- Дубликаты по `id` не создаются
- Прогресс-бар отображается в сообщении (редактируется)
- Rate limit соблюдается — между запросами пауза ≥ 60 секунд
- При 500+ транзакциях срабатывает пагинация
- После завершения бот показывает итоговый отчёт

### REQ-04: WebHook Setup — Real-time транзакции

**Current state:** Нет. Новые транзакции только через ручной `/mono_import`.
**Target state:** WebHook-сервер, принимающий уведомления от Monobank о новых транзакциях в реальном времени.

**Детали реализации:**

1. **WebHook-сервер** — отдельный модуль `mono/webhook.py` (FastAPI на том же порту, что и бот, или отдельный процесс)
2. **Установка WebHook:** Команда `/mono_setwebhook` — отправляет на Monobank URL сервера
3. **Формат запроса от Monobank:**
   ```json
   {
     "type": "StatementItem",
     "data": {
       "account": "UUID счёта",
       "statementItem": {
         "id": "ZuHWzqkKGVo=",
         "time": 1554466347,
         "description": "Покупка",
         "mcc": 7997,
         "amount": -95000,
         "currencyCode": 980
       }
     }
   }
   ```
4. **Обработка:**
   - Валидация типа (`type == "StatementItem"`)
   - Проверка дедупликации: есть ли уже `mono:{id}` в Sheets?
   - Если новая — категоризация по MCC, конвертация amount, запись в Sheets
   - Ответ: HTTP 200 (обязательно, иначе Monobank отключит webhook)
5. **Timeout:** Monobank ждёт ответ 5 секунд. Если нет ответа — повтор через 60 сек, потом 600 сек, потом отключение
6. **Логирование:** Все входящие WebHook логируются (дата, id, статус)

**Acceptance:**
- `/mono_setwebhook` устанавливает WebHook на текущий URL сервера
- При новой транзакции Monobank присылает POST → бот записывает в Sheets
- WebHook-сервер отвечает HTTP 200 в течение 5 секунд
- Дубликаты не создаются (проверка по `mono:{id}`)
- Если транзакция уже есть — HTTP 200 всё равно возвращается (не блокировать Monobank)

### REQ-05: Currency Rates — `/mono_rates`

**Current state:** Нет. Курсы не отображаются, конвертация не делается.
**Target state:** Команда `/mono_rates` — показывает актуальные курсы валют от Monobank.

**Детали реализации:**
- Запрос к публичному endpoint `GET /bank/currency` (без X-Token)
- Кэш на 5 минут (чтобы не долбить API)
- Показ курсов: USD/UAH, EUR/UAH, EUR/USD (bid/ask)

**Формат вывода:**
```
💱 Курсы Monobank

🇺🇸 USD → 🇺🇦 UAH: 41.25 / 41.85
🇪🇺 EUR → 🇺🇦 UAH: 44.80 / 45.50
🇪🇺 EUR → 🇺🇸 USD: 1.085 / 1.095
```

**Автоконвертация при импорте:**
- Если счёт в UAH — amount записывается в `Amount UAH`
- Если в USD — в `Amount USD`, + конвертация в UAH по текущему курсу
- Если в EUR — в `Amount EUR`, + конвертация в UAH по текущему курсу
- Используется средний курс (bid+ask)/2 на момент импорта

**Acceptance:**
- `/mono_rates` показывает актуальные курсы
- Курсы кэшируются на 5 минут (повторный вызов не делает запрос)
- При импорте транзакции конвертируются по курсу на момент импорта
- Если API курсов недоступен — конвертация не делается, amount = 0 в других валютах

### REQ-06: Sync Command — `/mono_sync`

**Current state:** Нет. Нужно вручную вызывать `/mono_import` для каждого периода.
**Target state:** Команда `/mono_sync` — автоматическая докачка пропущенных транзакций с момента последнего импорта.

**Алгоритм:**
1. Найти последнюю импортированную транзакцию в Sheets (макс. `time` среди `mono:*` source)
2. Если нет ни одной — показать: "Нет импортированных транзакций. Сначала сделай /mono_import"
3. Взять `from = last_time + 1 секунда`, `to = now`
4. Запросить выписку через `get_statement()`
5. Применить дедупликацию, категоризацию, запись
6. Если период > 31 дня — разбить на чанки
7. Rate limit: пауза 60 сек между запросами

**Пример вывода:**
```
🔄 Синхронизация с Monobank
Последняя импортированная: 28.05.2026, 14:30

✅ Добавлено: 5 новых транзакций
📊 Потрачено: -1 230 UAH
💰 Получено: +0 UAH
```

**Acceptance:**
- `/mono_sync` находит последнюю транзакцию и докачивает новые
- Если с момента последнего импорта прошло > 31 дня — разбивает диапазон на чанки
- Rate limit соблюдается
- Дубликаты не создаются
- Если новых транзакций нет — сообщает "Всё актуально"

## 3. Boundaries

### In Scope

- Асинхронный клиент Monobank API с rate limiter'ом
- Импорт выписки за период (до 31 дня) с пагинацией
- Дедупликация по `id` транзакции
- MCC → категории проекта (базовый словарь)
- WebHook-сервер для real-time транзакций
- Курсы валют (отображение + конвертация при импорте)
- Синхронизация пропущенных транзакций
- Информация о клиенте и счетах
- Логирование ошибок и неизвестных MCC

### Out of Scope

- Исторические курсы валют на дату транзакции — используется курс на момент импорта
- Автоматическая синхронизация по расписанию (cron) — Phase 5
- Поддержка других банков — только Monobank
- Ручная перекатегоризация импортированных транзакций — Phase 2 (уже в плане)
- Веб-интерфейс для Monobank данных — Phase 3 (PWA)
- Машинг неизвестных MCC через ИИ — вручную, через логи
- Экспорт Monobank данных — уже покрыто Google Sheets
- Push-уведомления о новых транзакциях — Phase 5

---

## 4. Constraints

- **Monobank API:** 1 запрос в 60 секунд (rate limit)
- **Monobank выписка:** максимум 31 день + 1 час за один запрос
- **Monobank выписка:** до 500 транзакций в ответе
- **Monobank WebHook:** ответ HTTP 200 в течение 5 секунд
- **Суммы:** в копейках/центах — обязательное деление на 100
- **Google Sheets API:** 60 запросов/мин на пользователя
- **Источник (Source):** импортированные транзакции маркируются как `mono:{id}`
- **X-Token:** хранится в `.env`, не в коде
