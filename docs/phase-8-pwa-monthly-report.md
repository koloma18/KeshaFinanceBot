# Phase 8 — Monthly Report Card в PWA

## Status: ✅ Complete

## Что сделано

Добавлена карточка **MonthlyReportCard** на дашборд PWA, зеркалирующая функциональность `/report` из Telegram-бота. Карточка размещена между `DailyStatsCard` (Неделя) и `BudgetCard`.

## Как работает

### Доходы / Расходы / Итог

- Фильтрация по текущему месяцу (`tx.month === English name`)
- Только типы `income` и `expense`
- Трансферы исключены (`tx.transferId?.trim()`)
- Суммы расходов через `Math.abs()`
- Итог = доход − расход, цвет зелёный при ≥ 0, красный при < 0

### Комментарий Кеши (🐿️)

5 уровней на основе `net`:

| Net | Комментарий |
|-----|-------------|
| > 10 000 ₴ | Кеша гордится тобой. Шикарный месяц! |
| > 0 ₴ | Кеша доволен. Так держать. |
| === 0 ₴ | Месяц в ноль. Стабильность. |
| > −5 000 ₴ | Кеша замечает утечку орехов. |
| ≤ −5 000 ₴ | Кеша в шоке от таких трат. |

### 🏆 Топ трат

- Группировка расходов по `tx.category`
- Сортировка по убыванию суммы
- Максимум 5 категорий
- Прогресс-бар CSS (`bg-kesha-expense`) с процентным соотношением
- Эмодзи через `getCategoryEmoji()`
- Пустая категория → "Другое"
- Блок скрывается, если расходов нет

### 🔁 Регулярные платежи

- `source.startsWith("recurring:")`
- Название: `comment || category || "Регулярный платёж"`
- Группировка по названию, максимум 3
- Сортировка по убыванию суммы
- Показывает общую сумму регулярных и % от расходов
- Блок скрывается, если нет ни одного регулярного платежа

### 📉 Сравнение с прошлым месяцем

- Отдельный `useMemo` с фильтром по `PREV_MONTH.name` и `extractYear(tx.date)`
- `getPrevMonth()` обрабатывает январь → декабрь (переход года)
- Доход/Расход/Итог с цветовыми дельтами:
  - `incomeDelta`: зелёный при росте
  - `expenseDelta`: красный при росте (`invert = true`)
- Блок всегда показан; если данных за прошлый месяц нет — выводится плейсхолдер "Нет данных за прошлый месяц"

### Пустое состояние

- Карточка с сообщением "Нет данных за этот месяц"
- Показывается, когда `income === 0 && expense === 0`

## Технические решения

**Клиентская агрегация** — никакого нового API-роута. Транзакции уже в стейте дашборда, `useMemo` дешёвый.

**Pure CSS прогресс-бары** — никаких Recharts или SVG. iOS Safari не страдает.

**Один новый useMemo** — только для предыдущего месяца. Все остальные данные расширяют существующий `useMemo` для monthStats.

**Transfer exclusion** в каждом цикле — консистентно с ботом и фиксом из commit 28dd165.

**Без селектора месяца** (MVP).

**Без предупреждений бюджета** внутри карточки — `BudgetCard` существует отдельно.

**Без новых зависимостей** — всё через существующие утилиты (`formatAmountInt`, `formatPercent`, `getCategoryEmoji`).

## Предусловие: фикс эксклюзии трансферов

**Commit 28dd165** — веб-агрегации считали переводы как доход/расход.

Исправлено в:
- `getBalance()` — суммирование балансов
- `getCategoriesSpending()` — группировка по категориям
- `getAccountBalances()` — разбивка по счетам
- `calcStats()` — статистика дня/недели

Фикс: `if len(r) > COL["TRANSFER_ID"] and r[COL["TRANSFER_ID"]]: continue` в каждом цикле.

## Ключевые компоненты и типы

### MonthlyReportCard (props)

| Проп | Тип | Описание |
|------|-----|----------|
| `monthLabel` | `string` | Название месяца (рус., напр. "мая 2026") |
| `income` | `number` | Доход за месяц |
| `expense` | `number` | Расход за месяц |
| `categories` | `SpendingByCategory[]` | Топ-5 категорий (опционально) |
| `recurringTotal` | `number` | Сумма регулярных платежей |
| `recurringItems` | `RecurringItem[]` | До 3 регулярных платежей |
| `prevIncome` | `number` | Доход прошлого месяца |
| `prevExpense` | `number` | Расход прошлого месяца |
| `prevMonthLabel` | `string` | Название прошлого месяца |
| `loading` | `boolean` | Состояние загрузки |
| `empty` | `boolean` | Нет данных за месяц |

### Вспомогательные функции

- `keshaComment(net)` — возвращает комментарий Кеши по net
- `deltaColor(delta, invert)` — цвет дельты (зелёный/красный)
- `deltaSign(delta)` — знак дельты (+/-)
- `getPrevMonth()` — возвращает `{name, year, label}` предыдущего месяца
- `extractYear(dateStr)` — год из "DD.MM.YYYY" (для проверки при декабрь→январь)

## Известные ограничения

- Только текущий месяц (нет селектора месяцев)
- Нет предупреждений бюджета внутри карточки (BudgetCard существует отдельно)
- Сравнение только с предыдущим месяцем (не с произвольным)
- Максимум 5 категорий, максимум 3 регулярных платежа
- Все суммы в UAH (нет конвертации валют)
