# Kesha Finance Tracker — Руководство пользователя

Кеша — твой финансовый надзиратель. Telegram-бот + веб-приложение для учёта доходов и расходов с характером.

---

## Telegram бот

> ☁️ **Бот работает 24/7 на fly.io.** Не нужно запускать локально.

Бот работает в чате Telegram. Все команды доступны через `/` или кнопки меню.

### Интерактивный `/help`

Вызови `/help` — Кеша покажет меню из 8 разделов с кнопками:

```
🆘 Что ты хочешь узнать?

[💰 Доход]         [💸 Расход]
[📊 Статистика]     [🎯 Бюджет и лимиты]
[🏦 Monobank]       [📋 Управление записями]
[🧠 Цитаты и стикеры] [⚙️ Настройки]

[📖 Полный список команд]
```

Нажми на раздел — получишь подробное описание команд с примерами. Кнопка «🔙 Ко всем разделам» возвращает назад.

**Пример:** Нажав «🎯 Бюджет и лимиты», увидишь:

```
🎯 Бюджет и лимиты

/budget 30000 — установить общий бюджет
/budget — посмотреть статус бюджета
/set_limit Кофе 2000 — лимит на категорию
/limits — все лимиты с прогрессом
/limit_alerts — настроить уведомления

Алерты приходят при 50%, 80% и превышении лимита.

[🔙 Ко всем разделам]
```

Также можно сразу открыть нужный раздел: `/help budget`, `/help mono`, `/help stats` и т.д.

### Статистика

#### `/today` — сегодня

```
📅 Сегодня

💰 Доход: +0 UAH
💸 Расход: -350 UAH
📊 Итого: -350 UAH

Топ трат:
  • Кофе: 250 UAH
  • Транспорт: 100 UAH
```

#### `/week` — текущая неделя

Показывает доходы, расходы и топ-3 категорий трат за последние 7 дней.

#### `/month` — текущий месяц

```
📆 Июнь 2026

💰 Доходы: 50 000 UAH
💸 Расходы: 32 450 UAH
📊 Баланс: +17 550 UAH

📈 Доход/Расход: 60.5% от доходов потрачено
```

#### `/balance` — общий баланс

```
🧾 Общий баланс
Доходы: 150 000 UAH
Расходы: 120 000 UAH
Итого: +30 000 UAH
```

Баланс считается за всё время существования таблицы.

#### `/top` — топ расходов

Показывает топ-5 категорий по расходам за текущий месяц с суммами и процентами от общих трат.

#### `/compare` — сравнение месяцев

Сравнивает текущий месяц с предыдущим по доходам, расходам и балансу. Показывает разницу в числах и тренд (↗ стало лучше, ↘ стало хуже).

#### `/last` — последние операции

Показывает 5 последних записей — дату, категорию, сумму.

### Бюджет и лимиты

Кеша следит, чтобы ты не потратила больше запланированного. Два уровня контроля:

#### Общий бюджет (`/budget`)

Установи лимит трат на месяц:

```
/budget 30000
```

Ответ:
```
✅ Бюджет на Июнь: 30 000 UAH
```

Проверить состояние бюджета — просто `/month` или `/balance`. При достижении порогов бот отправляет предупреждения:
- ⚠️ 50% бюджета: «потрачено 15 000 из 30 000»
- ⚠️ 80% бюджета: «осталось всего 6 000»
- 🚫 100% бюджета: «бюджет исчерпан»
- ‼️ Превышение: «перерасход на X»

Чтобы удалить бюджет:
```
/budget 0
```

#### Лимиты по категориям (`/set_limit`)

Задай лимит на конкретную категорию:

```
/set_limit кофе 2000
```

Ответ:
```
✅ Лимит на Кофе: 2 000 UAH в месяц
```

#### `/limits` — все лимиты

Показывает красивый прогресс-бар по каждой категории с лимитом:

```
🚦 Июнь 2026

🎯 Общий бюджет: 30 000 UAH   ███████░░░ 64.9%

☕️ Кофе: 2 450 / 3 000 UAH    ████████░░ 81.7%  ⚠️
🛒 Маркетплейсы: 12 000 / 5 000 UAH  ██████████ 240%  ‼️
🚕 Такси: 850 / 2 000 UAH     ████░░░░░░ 42.5%
```

#### `/limit_alerts` — настройки уведомлений

Включай/выключай уведомления о превышении лимитов. Можно настроить отдельно:
- 50% предупреждение
- 80% предупреждение
- 100% лимит исчерпан

Уведомления приходят сразу при добавлении расхода, если порог был пересечён.

### Monobank (авто-импорт)

Если у тебя есть Monobank и ты [получила X-Token](https://api.monobank.ua/), бот может автоматически загружать операции.

> ⚠️ **Важно:** Monobank API разрешает **только 1 запрос в 60 секунд**. При превышении — ошибка 429. Бот сам соблюдает этот лимит и ждёт между запросами.

#### `/mono_import [days]` — импорт выписки

Импортирует операции за указанное число дней (по умолчанию 7, максимум 31):

```
/mono_import 7
```

Бот показывает прогресс:
```
🔄 Подключаюсь к Monobank...
Запрошу выписку за последние 7 дн.

✅ Импортировано 23 операции
  Новых: 15
  Пропущено (дубликаты): 8
```

Дубликаты определяются по ID операции Monobank — одна и та же операция никогда не запишется дважды.

**Категоризация:** операции автоматически получают категорию по MCC-коду (Merchant Category Code):
- 5411 → Еда (супермаркеты)
- 5812 → Еда (рестораны)
- 4121 → Такси
- и т.д. (более 100 кодов)

Если категория не определена — операция попадёт в «Другое». Потом можно перекатегоризировать через `/recategorize`.

#### `/mono_day <дата> [счёт]` — выписка за день

Показывает операции Monobank за конкретную дату:

```
/mono_day 25.05.2026
/mono_day 25.05.2026 1    # только первый счёт
```

#### `/mono_info` — счета и балансы

Показывает все счета Monobank и текущие балансы:

```
💳 Счета Monobank:

🏦 Чёрная карта: 12 450.50 UAH
💵 USD карта: 340.00 USD
🏦 Белая карта: 5 200.00 UAH
```

#### `/mono_rates` — курсы валют

Показывает актуальные курсы валют из Monobank API:

```
💱 Курсы валют:

USD → UAH: 41.50 / 41.80
EUR → UAH: 45.20 / 45.60
```

#### `/mono_sync` — синхронизация

Запускает синхронизацию пропущенных операций с момента последнего импорта.

### Цитаты и напоминания

#### `/quote` — случайная цитата

Кеша присылает случайную финансовую цитату. Например:

```
🧠 «Богат не тот, у кого много денег, а тот, у кого расходы меньше доходов.»

Цитат в коллекции: 50
```

#### `/quote_time` — ежедневная цитата

Установи время, когда Кеша будет присылать цитату дня:

```
/quote_time 10:00
```

Ответ:
```
✅ Цитата дня будет приходить каждый день в 10:00
```

Чтобы отключить:
```
/quote_time off
```

#### `/reminder` — ежедневный итог

Настрой ежедневный отчёт в конце дня:

```
/reminder 21:00
```

Ответ:
```
⏰ Ежедневный итог будет приходить в 21:00
```

В указанное время Кеша пришлёт статистику за день: доходы, расходы, итог.

### Настройки (токсичность, мат, стикеры)

#### `/settings` — главное меню настроек

Открывает интерактивное меню с кнопками:

```
⚙️ Настройки Кеши

Текущий стиль: Бурчливый 😤
Мат: разрешён

[🤬 Стиль общения]
[🤐 Мат: вкл/выкл]
[😈 Стикеры]
[💱 Валюта: UAH]
```

#### Стиль общения (токсичность)

4 уровня:

| Уровень | Описание | Пример |
|---------|----------|--------|
| `soft` 😇 | Мягкий | «Записала. Молодец, что ведёшь учёт.» |
| `grumpy` 😤 | Бурчливый (по умолчанию) | «Записал. Опять траты. Кошелёк смотрит на тебя с презрением.» |
| `hard` 🤬 | Жёсткий | «Записал. Ну и нахрена тебе это было нужно?» |
| `random` 🎲 | Случайный | Каждый раз случайный уровень из трёх |

#### Мат (`profanity_enabled`)

Включает/выключает нецензурную лексику в жёстком режиме. Если мат выключен — жёсткий режим использует бурчливые фразы без мата.

#### Валюта (`/set_currency`)

Установи основную валюту отображения:

```
/set_currency USD
```

Доступные валюты: `UAH`, `USD`, `EUR`, `USDT`.

### Работа с категориями

#### `/categories` — список категорий

Показывает все доступные категории расходов и доходов.

#### `/add_category` — новая категория

Добавить свою категорию в дополнение к встроенным:

```
/add_category expense Книги
/add_category income Кэшбек
```

Первый аргумент — тип: `expense` или `income`. Второй — название категории.

Новая категория сразу появляется в кнопках меню и доступна для выбора.

#### `/recategorize` — сменить категорию

Если операция записалась в неправильную категорию:

```
/recategorize 15 еда
```

Где `15` — номер строки (видно в `/last`), `еда` — новая категория.

Ответ:
```
🔄 Операция #15 перекатегоризирована: Такси → Еда
```

### Удаление операций

#### `/delete_last` — удалить последнюю

Удаляет самую свежую операцию. Полезно, если ошиблись с суммой:

```
/delete_last
```

Ответ:
```
↩️ Удалена последняя операция:
   💸 -350 Кофе
```

#### `/delete` — удалить по номеру

Удалить конкретную операцию (номер из `/last`):

```
/delete 12
```

Удалит операцию №12 с подтверждением.

## Веб-приложение

Веб-приложение доступно по адресу `http://localhost:3000` (или твой домен/IP).

### Dashboard (Сводка)

Главная страница показывает всё самое важное:

**Карточка баланса:**
- Общий баланс (доходы − расходы)
- Всего доходов
- Всего расходов
- Дата последнего обновления

**Статистика за сегодня и неделю:**
- Две карточки рядом: «Сегодня» и «Неделя»
- Доход (+), Расход (−), Итого

**Бюджет:**
- Прогресс-бар общего бюджета (если установлен)
- Потрачено / Лимит / Осталось
- Процент выполнения

**Курсы валют (Monobank):**
- USD/UAH, EUR/UAH — покупка/продажа
- Обновляется при загрузке страницы

**Последние транзакции:**
- 5 последних операций с иконками категорий
- Дата, категория, комментарий, сумма
- Цветовая кодировка: зелёный = доход, красный = расход

**Pull-to-refresh:** потяни страницу вниз пальцем → данные обновятся.

### Транзакции

Страница `/transactions` — полная история операций:

- **Фильтры:** по категории, типу (доход/расход), дате (месяц)
- **Поиск:** по комментариям и категориям
- **Пагинация:** по 20 операций на страницу
- **Сортировка:** по дате (новые сначала)

Каждая строка показывает:
- Иконка категории (эмодзи)
- Дата и время
- Категория
- Комментарий
- Сумма (цветом: доход/расход)
- Источник (manual / monobank)

Веб-приложение поддерживает установку как PWA:

1. Открой сайт в Safari (iPhone) или Chrome (Android)
2. Добавь на домашний экран (см. [INSTALL.md → PWA](INSTALL.md#установка-pwa-на-телефон))
3. Открывай как обычное приложение — без адресной строки браузера

**Что работает офлайн:** ранее загруженные страницы дашборда и транзакций кэшируются Service Worker'ом. Новые данные загружаются при подключении к интернету.

## FAQ

### Бот не отвечает на команды

1. Бот работает 24/7 на fly.io — локальный запуск не требуется
2. Проверь статус на fly.io: `fly status`
3. Проверь логи: `fly logs` — возможно ошибка в коде или токене
4. Попробуй `/start` — бот должен ответить
5. Если бот не отвечает — `fly restart` и проверь `fly logs`

### Ошибка Google Sheets: «insufficient permissions»

1. Проверь, что Service Account добавлен в таблицу как Editor
2. Убедись, что `SPREADSHEET_ID` правильный
3. Проверь `GOOGLE_SERVICE_ACCOUNT_EMAIL` — должен быть точный email из JSON-ключа
4. Проверь `GOOGLE_PRIVATE_KEY` — `\n` должны быть именно `\n` в `.env`

### Monobank: ошибка 429 «Too Many Requests»

Monobank разрешает только 1 запрос в 60 секунд. Бот сам ждёт, но если ты часто вызываешь команды — может упереться в лимит. Подожди минуту и попробуй снова.

### Как сбросить все данные?

1. Открой Google Таблицу
2. Очисти лист `Transactions` (оставь заголовки)
3. Очисти листы `Budgets` и `Settings` при необходимости
4. Перезапусти бота — при `/start` все настройки сбросятся на значения по умолчанию

### Как поменять валюту по умолчанию?

Через команду `/set_currency` в боте. Или в `.env` измени `PRIMARY_CURRENCY` и перезапусти бота.

### Можно ли использовать без Monobank?

Да. Monobank — опциональная функция. Все основные команды работают без Monobank-токена.

### Стикеры не отправляются

1. Убедись, что стикеры включены: `/stickers` → «Включены»
2. Проверь, что частота не «Только > 2000» для мелких сумм
3. Если стикер-пак был удалён из Telegram — конкретный стикер не отправится, но бот продолжит работу

### Как перенести данные на другой аккаунт?

1. Экспортируй данные через `/export` → получишь CSV
2. Создай новую Google Таблицу, дай доступ Service Account
3. Импортируй CSV в новую таблицу (Google Sheets: File → Import)
4. Обнови `SPREADSHEET_ID` в `.env`
5. Перезапусти бота

### Веб-приложение не загружается

1. Убедись, что `npm run dev` запущен в папке `web/`
2. Проверь `.env.local` — должен содержать те же переменные, что и `.env`
3. Открой `http://localhost:3000`
4. Если ошибка «Failed to fetch» — проверь консоль терминала на ошибки Google Sheets

### Как обновить список категорий?

1. Встроенные категории обновляются с кодом бота
2. Свои категории добавляй через `/add_category`
3. Удалить кастомную категорию можно через Google Sheets — лист `Categories`

### Бот перестал работать после обновления

1. Проверь что код запушился: `git push`
2. Задеплой обновление: `fly deploy`
3. Проверь логи: `fly logs` — ищи ошибки
4. Если ошибка — откати изменения (`git revert`) и `fly deploy` заново
